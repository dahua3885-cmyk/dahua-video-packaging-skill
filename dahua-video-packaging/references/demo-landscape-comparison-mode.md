# 横屏多包装比较模式

当口播本身在讲“两种／三种视频包装”“同一条内容如何换不同剪辑样式”或“展示以前剪过的样板”时使用。它与标准界面演示共用固定人物、字幕、音频和验收合同，但主画面从“持续网页举证”改成“真实成片样板 + 解释”。

## 进入条件

- 用户要求同一条源视频做两种以上包装并在一条视频里比较。
- 用户要求横屏讲解，左边放以前剪过的视频，右边放文字，右下放讲解人物。
- 口播的核心对象是“包装样式／剪辑 Skill 本身”，而不是某个网站的连续操作。

没有外部参考视频也可以执行。优先把同一条源视频或已经完成的历史版本重构为真实动态样板；参考片只用于学习信息关系，不是必需素材。

## 默认结构

1. **开头总览**：同时出现全部真实样板，按口播顺序标为 `01 / 02 / 03`。每个样板保持动态，只承担“接下来会讲哪几种”的总览作用。
2. **逐项讲解**：左侧放当前包装的真实动态样板；右侧放名称、视觉关系、优势和适用内容；右下保留固定讲解人物；底部保留单行字幕。
3. **往期举证**：口播说“可以看我往期视频”时，直接展示真实往期作品缩略图或短动态片段，不用文字占位替代。
4. **结尾收束**：用三种类型的简明总表或 CTA 收束，不继续随机复用案例素材。

## 标题规则

- 发布标题必须让第一次看到的人立即知道两件事：这是视频剪辑／包装内容；它由 AI 自动完成或由 AI Skill 驱动。
- 使用“两层标题”：小标题说明方法和范围，主标题说明结果或动作。
- 三种包装的已验证表达：
  - 小标题：`AI 自动剪辑包装 · 三种真实案例`
  - 主标题：`我用 3 个 AI Skill，自动剪辑包装视频`
- 数量、对象和结果必须按当前视频真实内容改写，不机械固定为“3”。
- 禁止把 `一条内容，三种包装`、`LANDSCAPE TEST`、`横屏测试版` 等内部工作名直接当发布标题。

## 样板与文字关系

- 左侧样板是证据，必须播放对应包装的真实视频，不得用静态封面代替整段。
- 右侧文字只解释“这种包装是什么、为什么这样排、适合什么”，不得重复字幕全文。
- 当前样板的名称和编号必须常驻可辨认，例如：
  - `01 普通口播包装展示`
  - `02 小窗口包装展示`
  - `03 Skill 包装展示`
- 标签放在平台安全区内。竖屏发布时不要贴死最左上角，应向右、向下留出抖音头像、状态栏和视线盲区；先叠平台 UI 安全区检查图再冻结位置。

## 三种样板的画幅合同

- **普通口播**：样板可保留竖屏比例放在左侧竖框内，人物是样板主体。
- **小窗口包装**：样板按原包装比例完整展示；人物头发最高点和头部轮廓必须完整。发生切头时优先整体缩小或改用 `contain`，禁止继续放大裁切。
- **Skill 包装**：样板必须以横屏界面比例展示真实页面／操作，样板内的人物仍是小窗口；禁止把 Skill 段错误替换成竖屏人物大画面。
- **讲解人物**：始终是右下独立小窗，执行固定 `210×352 @ (1676,690)` 合同；不要把左侧样板里的人物误当作讲解人物。

## 版本与返修

- 用户说“做一个横屏测试对比效果”时，新建横屏工程或递增版本，保留原竖屏和上一版横屏。
- 用户只改标题、标签位置或某一种样板时，冻结其余时间轴、字幕、音频和已经通过的版式，只做差量检查与新版本导出。
- 文件名使用 `v01 / v02` 递增并描述差异；不得覆盖旧文件。

## 验收

- 开头 `1–4s`：标题完整，AI 自动剪辑主题明确，全部样板与编号可见。
- 每个逐项段：样板类型正确且保持动态，右侧文字与当前口播对应，讲解人物和字幕不遮挡。
- Skill 段：横屏界面比例正确；小窗口段：人物头部完整。
- 往期视频句：真实往期作品已经出现。
- 最终 MP4：完整解码；分辨率、帧率、时长正确；未授权剪口播时主音频 MD5 与源片一致。
- 横竖屏或标题测试：旧版文件仍然存在。
