# 横屏固定版式合同

本合同适用于本 Skill 的 `1920×1080` 横屏视频。以下参数不是创意建议，而是发布前必须逐项验证的硬约束。只有用户明确点名要求修改某一项时，才允许覆盖该项；“页面挡住了”“字太长”“素材不好放”都不是改动理由。

## 固定项与创意项

| 类型 | 内容 | 自由度 |
| --- | --- | --- |
| 固定 | 画布、人物尺寸与位置、人物圆角、字幕字体与位置、字幕底板、黄框样式、安全区、验收流程 | 低；默认禁止改动 |
| 可变 | 当前句使用哪段真实素材、页面裁切与缩放、切镜头时机、是否生成语义页、结尾视觉隐喻 | 中；必须服从口播 |
| 禁止 | 为了“更有设计感”放大人物、移动人物、恢复全宽字幕栏、增加人物描边、让黄框常驻或逐句出现 | 无 |

## 画布

- 分辨率：`1920×1080`。
- 帧率：跟随已剪好源片；默认 `30fps`。
- 网页、软件、Markdown、文件夹和结果页为主画面。
- 所有重要证据优先落在 `x=40–1640, y=40–900` 的阅读安全区。
- `y=900–1080` 视为字幕保留带，黄框和关键证据不得进入。
- 如果证据被人物或字幕占位区遮挡，调整页面的 `scale / crop / x / y` 或更换镜头；不得移动人物、抬高字幕或让黄框盖在遮挡层上。

## 人物小窗

- 尺寸：`210×352`。
- 坐标：`x=1676, y=690`。
- 右边距：`34px`；底边距：`38px`。
- 圆角半径：`18px`。
- 取景：头部到腰部，保留自然手势；人物保持水平、居中，不使用整条竖屏画面。
- 用一个自然正视的中性关键帧建立固定裁切：头发最高点落在小窗 `y=45–60`，鼻梁中心落在 `x=97–113`。同一源片全程沿用同一个裁切和旋转参数，不逐帧追踪人物，避免小窗抖动。
- 源片裁切范围允许随人物素材调整，但输出框尺寸和坐标不得改变；画面存在真实水平线或垂直线时，只允许做一次全片固定旋转，校正后倾斜误差不得超过 `1°`。
- 不加白边、灰边、彩边、阴影、标签或外框。
- 不给人物叠加半透明黑灰层、颜色蒙层或蓝光；不得改变脸部亮度和肤色。
- 全片固定右下，不因章节、页面重点或素材变化移到左侧，也不放大或缩小。
- 人物与页面冲突时，调整页面，不调整人物。

## 字幕

- 固定使用 ffmpeg `subtitles` 滤镜的 libass 渲染，不混用剪映、浏览器 CSS 或其他字体度量。
- 字体文件：Skill 内附带的 `assets/fonts/NotoSansSC-VF.ttf`。哈希不一致时停止并报告，不得使用系统字体替换。
- ASS 样式固定为：`Fontname=Noto Sans SC, Fontsize=44, PrimaryColour=&H00FFFFFF, OutlineColour=&H00000000, BackColour=&H00000000, Bold=-1, BorderStyle=3, Outline=12, Shadow=0, Alignment=2, MarginL=90, MarginR=90, MarginV=90`。
- 底板随当前字幕宽度变化；不得使用全宽底栏。
- 每次只显示一条单行字幕。为避开右下人物，字幕文字本体宽度不得超过 `1340px`；libass 黑底外缘不得超过 `x=1652`。
- 超过宽度时按真实语义与气口拆成下一条字幕，不缩小字号、不压扁字体、不改成双行。
- 字幕必须忠实原音，不概括、不润色、不合并多句话。
- 字幕直接出现和消失，不加动画；禁止渐显、弹跳、逐字动画、放大、位移和更换位置。

## 黄色重点框

- 颜色：`#EBAB14`。
- 线宽：`3px`。
- 圆角：`10px`。
- 目标边界取“当前证据所有可见像素的最小外接矩形”；`x1/y1` 向下取整、`x2/y2` 向上取整，再向四边固定外扩 `10px`。描边居中绘制，线条不得穿过文字、数值、按钮或图标。
- 只画轮廓，填充透明度固定为 `0%`；默认不加文字标签、箭头、光晕或大面积黄色底色。
- 同一时刻最多一个框；需要指出多个证据时按口播顺序分时出现。
- 黄框只能标“观众不容易一眼找到、但当前句必须看到”的关键证据。
- 页面标题、结果数字或当前操作已经足够明确时不加框；过程镜头、滚动镜头、鼠标框选正在发生时不加框。
- 底图先停稳至少 `0.12s`。黄框时间由逐词字幕真源驱动：开始帧与结束帧均使用 `ceil(时间秒 × fps)` 向后吸附到帧边界；开始时间取关键词首字时间，结束时间取证据短语末字时间。不得凭听感手填近似秒数。
- 不得提前出现，不得延续到下一句，不得逐句常驻。
- 黄框不得进入人物占位区或字幕占位区。发生冲突时重构页面镜头，不移动固定层。

## 页面与语义的创意空间

以下内容允许创意判断：

- 为当前句选择最能举证的真实录屏、截图、网页、文件夹、报告或结果页。
- 在不改变固定层的前提下调整页面缩放、裁切和停留时长。
- 当前句没有合适真实画面时，生成与语义对应的简洁示意页；必须明确它是示意，不能伪造真实数据或操作结果。
- 用直接切镜头、短交叉叠化或必要的真实连续操作表达过程。

创意判断必须同时满足：当前句对应、证据真实、手机尺寸可读、人物与字幕不遮重点。

## 对标覆盖规则

- 用户没有另行指定视觉参考时，严格使用本合同。
- 用户提供新对标并明确说“按这个效果”时，先抽取至少 `10` 张代表帧，测量页面构图、开头结构、镜头节奏和素材关系，生成项目级 `reference_contract.md`。
- “按这个效果”只授权调整创意项，不自动授权改变人物、字幕、黄框等固定层。用户必须明确说出要改的人物／字幕／黄框项目，才能覆盖对应固定值。
- 新合同必须在首轮渲染前冻结；未测量完成不得开始全片包装。
- 用户只要求改变素材、语义画面或某个局部时，不得顺带修改本合同中的其他固定项。

## 规则优先级

- 本合同的固定值优先于 `video-use` 中关于人物小窗、字幕、标注的艺术自由和示例参数。
- `video-use` 只提供 ffmpeg 合成、音频保护和成片验证方法，不得重新决定本合同中的视觉参数、工程目录或是否剪切。
- 用户未授权剪辑时，跳过 `video-use` 的分段 EDL、切点淡化和重排流程，直接在完整连续源片上完成页面、人物与字幕合成。
- 固定合成顺序为 `页面 → 页面运动与黄框 → 人物 → 字幕`。人物之后禁止任何全屏效果或全局调色。
