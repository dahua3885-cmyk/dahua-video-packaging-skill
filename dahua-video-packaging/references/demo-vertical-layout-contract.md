# 竖屏固定版式合同

本合同适用于本 Skill 的 `1080×1920` 竖屏演示视频。用户要求“人物右下角”“竖屏演示”“网页／Skill 画面做主视觉”时，默认执行本合同，不再临场重排人物、字幕和主证据区。

## 发布规格

- 逻辑画布：`1080×1920`，默认 `30fps`。
- 文本密集型发布版默认原生渲染为 `1440×2560`；所有坐标按 `4/3` 等比缩放。`1080×1920` 只作为样片或用户明确指定的发布规格。
- 禁止把已经渲染好的 1080 成片机械放大冒充 2K。2K 必须从 HTML／原始素材重新采样渲染，并检查标题、字幕、网页小字的边缘。

## 固定人物与字幕

- 人物窗口：`x=580, y=1285, width=450, height=445`。
- 人物裁切：`object-fit: cover; object-position: 50% 43%`。
- 人物圆角：`48px`；全片固定右下，不逐场景换边、放大、缩小或消失。
- 字幕框：`x=60, y=1165, width=960, height=88`，位于人物头顶上方。
- 字幕：Noto Sans SC，`48px / 1.5 / 500`，白色 `#F4F4F1`，单行居中。长句按语义和气口拆分，禁止拆词、双行或压缩字号。
- 人物和字幕发生冲突时，重构主证据区；不得移动固定层。

## 主证据区

- 主证据安全区：`x=60–1020, y=120–1080`。
- 每段默认按“当前问题／动作标题 → 一句解释 → 对应真实截图、录屏或旧成片”组织。
- 当前标题只描述正在讲的语义，例如“Skill 是什么／去哪里找／怎么安装／怎么创建”；禁止用一个巨大总标题常驻全片，也禁止提前展示后续章节答案。
- 默认不显示“第几页／共几页”等内部页码。章节序号只有在口播结构需要时才作为内容层级出现。
- 左侧或上方出现无效空白时，优先把标题、解释和证据向阅读起点对齐；不要为了对称留下大块空区。
- 真实页面、旧成片和操作证据优先占最大面积。装饰卡片不得挤压到“只能证明有页面、但看不清页面”的程度。

## 原片自带封面

- 先逐帧确认源片封面结束帧、第一帧正文和第一字音频。
- 源片自带的连续封面帧只全屏播放一次；进入正文后，人物小窗从第一帧不带封面文字的正文画面开始。
- 人物、主音频、字幕和语义时间轴必须一起平移。禁止把同一组封面帧再次缩进右下人物小窗。
- 用户已确认的封面底版立即写入冻结表。后续正文返修不得重做封面；只有用户明确点名时才修改对应封面层。

## 合成与清晰度

- 合成顺序固定为：`主证据／语义页 → 页面运动与标注 → 人物 → 字幕`。
- 同一个证据跨多句口播持续存在时，复用同一个画面容器；字幕换句不等于换画面。
- 禁止在句子边界叠入第二张近似截图并同时做透明度、位移或缩放，这会造成重影和跳动。
- 发布前对所有证据切换点前后至少各抽 `3` 帧，并连续播放检查。

## 固定与可变

| 类型 | 内容 |
| --- | --- |
| 固定 | 画布比例、人物坐标、字幕坐标、主证据安全区、合成顺序、封面继承、2K 重渲规则、边界抽帧 |
| 可变 | 当前标题文案、真实素材选择、页面裁切、必要标注、语义页的具体关系表达 |
| 禁止 | 为了塞内容缩小关键字、随场景移动人物／字幕、重复小窗封面、用近似截图叠层过渡、低清成片直接放大 |
