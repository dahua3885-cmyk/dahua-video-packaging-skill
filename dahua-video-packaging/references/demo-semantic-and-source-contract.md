# 语义与素材硬合同

本合同限制“画面何时出现、素材是否可信、过程是否完整”。具体选哪一段素材仍可判断，但不得破坏下列关系。

## 开头与案例边界

- 标准演示模式的开头总起句只建立整条视频的主题，不提前进入第一个案例、结果页或工具操作。
- 标准演示模式在口播未说到具体案例前，使用中性概览页、主题页或与总起句直接对应的示意页；禁止用多个案例拼贴、大结果卡或无关界面抢跑。
- 若整条视频的主题本身就是比较两种以上包装／剪辑效果，改用横屏比较模式：开头允许同时展示全部真实样板，必须用 `01/02/03` 与准确类型名标识，只做总览，不提前展开某一项的结论。具体执行 [demo-landscape-comparison-mode.md](demo-landscape-comparison-mode.md)。
- 从口播第一次明确说出案例对象的关键词开始进入该案例。例如说到“第一个／C 盘”才出现 C 盘画面，说到“腾讯管家”才进入腾讯管家。
- 口播先讲问题、后讲所用工具时，先把问题讲明白，再进入工具界面；不得用工具界面代替问题本身。
- 每个案例至少按实际口播建立“问题 → 尝试／过程 → 关键证据 → 结果”闭环。口播没有其中某一环时不补造。
- 最后一个案例结束后，立即停止复用任何案例录屏。总结、观点和行动建议必须改用对应的结论页、主题页或新语义画面，禁止视觉语义倒退。

## 原片封面、基准版本与局部返修

- 原片自带连续封面帧时，先逐帧确定封面结束帧、正文第一帧和第一字音频。封面只全屏播放一次；人物小窗从第一帧不带封面文字的正文画面开始。
- 人物、主音频、字幕和语义时间轴必须一起平移。禁止把同一组封面帧再次缩进人物小窗。
- 用户确认的发布封面或原片封面底版写入冻结表。后续正文返修不得重新设计封面，除非用户明确点名。
- 用户说“在前面那一版基础上修改”时，该版工程、视觉基调、信息架构和已确认模块是唯一底稿。只移植用户明确认可的新模块，不得借返修重做成另一套视频。

## 语义触发与证据类型

- 口播第一次点名账号、作品、人物、案例、工具、步骤或结果时，对应证据从该句第一个播放帧进入。允许最多提前约 `0.2s` 建立上下文；不得晚到后半句，也不得提前展示下一项答案。
- 讲账号用真实主页；讲“多少条作品／拆了多少条视频”用作品墙；讲具体人物或收入案例用对应原视频，优先选择能认出受访者、采访关系和结果的片段。
- 用户点名已经做过的 Skill、网站、报告或案例成片时，先全盘检索并复用真实旧成片，不得用抽象卡片、近似截图或重画假界面替代。
- 案例原视频有“爆点前置”时，优先使用能建立人物与结果认知的开头爆点；若开头只有余额、数字或无上下文素材，改选更有信息量的采访画面。
- 静态截图负责讲页面结构和结果阅读；真实录屏／旧成片负责讲点击、滚动、生成、变化和动态案例。不能用一张静态图贯穿完整过程。
- “第 X 关／第 X 步／第 X 项”先使用独立介绍页，再进入对应案例证据；同类章节保持同一叙事顺序。

## 多状态过程

- 一句话或连续几句描述两个以上真实状态时，画面必须展示对应的多个状态。例如“开始扫描 → 一直找不到 → 不能删除”不能全程只放一张扫描图。
- 扫描、加载、滚动、鼠标框选、点击、执行和结果变化只要承担因果关系，就保留真实连续运动。
- 原过程太慢时，优先加速真实录屏；允许按语义切到真实中间状态和真实结果，但不得用静态截图组伪装连续操作。
- 加速前后必须保持动作方向、起点、终点和因果顺序。加速后的关键状态至少停留到能读清，最终结果至少稳定停留 `1s`。
- 原素材已经存在鼠标框选或系统选中状态时，保留原动作，不再叠加重复黄框。

## 同层复用与边界稳定

- 同一个页面、作品墙或案例视频跨多句持续时，复用同一个容器并延长时间。字幕换句不等于换画面。
- 禁止在句子边界叠入第二张近似截图，并同时做透明度、位移或缩放动画。
- 每个证据切换点前后至少各抽 `3` 帧并连续播放；用户指出跳点时另做 `±0.3s` 逐帧联系表。
- 画面变化只允许由当前语义对象变化、真实过程状态变化或章节关系变化触发；仅字幕换行不得触发画面重建。

## 字幕真源

- 使用逐词、逐字时间戳的原音转写作为唯一字幕真源；禁止使用概括字幕、旧版本字幕或根据画面反写口播。
- 首轮转写后做一次专项听校，逐项核对：否定词、数量、容量、百分比、产品名、英文名、技术名词和结果数字。
- 专有名词和数字同时对照真实页面文字；页面与耳听冲突时回听原音，不凭页面猜口播。
- 对低置信度词、同音词和含义可能反转的词必须回听对应片段；未确认不得进入完整预览。
- 字幕允许按气口拆成多条单行，但文字本身必须保持原话，不删掉“不、没、不能、不给”等改变含义的词。
- 每次修改素材切点、变速或画面时间轴后，重新核对对应字幕时间；不得只复用旧时间戳。

## 素材清洗

- 所有辅助录屏在使用前建立安全区间，至少连续检查开头 `2s`、结尾 `2s` 和全片每 `1s` 抽帧。
- 成片任何一帧不得出现 OBS、录屏控制栏、错误窗口、桌面隐私、文件路径隐私、通知或与当前语义无关的应用界面。
- OBS 或录屏控制界面出现在素材头尾时，从源时间段层面排除，不靠遮罩盖住。
- 所有辅助录屏音轨静音；人物口播源是唯一主音频。
- 真实录屏和页面素材必须记录来源路径与安全时间段，禁止在渲染脚本里临时凭印象截取。

## 合成层级与冻结

- 最终合成顺序固定为：`页面／语义底图 → 页面运动与黄框 → 人物小窗 → 字幕`。
- 人物小窗之后只允许叠加字幕；不得再叠加全屏灰层、颜色层、蓝光、暗角或页面遮罩。
- 不对已合成人物的整张画面做全局调色。页面需要调色时只处理页面层；人物保持源片亮度和肤色。
- 用户确认的人物、字幕、页面区间、黄框或封面任一层都要写入冻结表。局部返修只修改点名层和点名时间段。
- 修改字幕不动人物，修改黄框不换素材，修改封面文字不换人物帧，去人物边框不重建背景时间轴。
- 任何被当作整片底图或整片中间母版的文件，其有效画面时长必须覆盖完整正片；禁止用 `eof_action=repeat` 或末帧冻结掩盖中间资产过短。
