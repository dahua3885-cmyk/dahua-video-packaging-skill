# 发布前验收清单

## 真源

- [ ] 人物视频是用户最后点名的版本。
- [ ] 原音频未被预览文件或旧版本替换。
- [ ] 口播文本、字幕和章节来自同一主源。
- [ ] 已建立 `freeze-ledger.md`；用户指定的基准版本、封面、人物、字幕、视觉基调和认可模块均已冻结。
- [ ] 已建立 `semantic-evidence-map.md`；账号、作品、具体案例、步骤和结论均有独立真实证据与触发帧。
- [ ] 已生成 `first_pass_gate.json`，源片与基准版本校验值、允许修改范围和冻结层完整。

## 画面

- [ ] 1080×1920，30fps，画面没有被二次拉伸。
- [ ] 未明确要求换边时，人物窗口复用右下固定母版：`580,1285,450,445`。
- [ ] 字幕复用固定母版：`60,1165,960,88`，48px、500、白色单行，无黄色关键词。
- [ ] 顶部有留白，标题不顶边。
- [ ] 字幕在人像上方且未被卡片、图片、Logo 遮挡。
- [ ] 开头完整工具列表没有被简写。
- [ ] 每个工具使用产品 Logo，Logo 方块尺寸统一。
- [ ] “视觉部门”三个卡片都已放入 Logo。
- [ ] 没有持续放大、弹跳或突然弹出。
- [ ] 没有整页统一淡入或 PPT 式翻页；标题、节点、连线、状态和结论按口播语义逐步建立。
- [ ] 至少抽查一组流程动画的动作前、动作中、动作后，确认后续板块没有提前显示。
- [ ] 原片自带封面时只全屏播放一次，人物小窗从无封面文字的正文第一帧开始。
- [ ] 账号用主页、作品用作品墙、具体人物／收入案例用对应原视频或真实旧成片，没有串错证据。
- [ ] “第 X 关／第 X 步／第 X 项”先有独立介绍页，再进入案例；同类章节顺序一致。
- [ ] 当前证据从对象第一次被说出的播放帧进入，没有晚到后半句；未讲到的并列项保持隐藏。
- [ ] 同一证据跨字幕换句时复用同一容器；视觉切换点前后各抽 `3` 帧，无重影、重复叠层和跳动。
- [ ] 页面标题小而有结论；比较对象是一级大字，解释是二级；无“第几页／共几页”内部页码。
- [ ] 正文只使用固定场景语法；同类内容全片复用同一模板，没有每个章节重新发明版式。

## 完整渲染闸门

- [ ] `validate_first_pass_gate.py validate --workflow small-window` 已通过。
- [ ] 代表性检查包覆盖封面→正文、第一次真实证据、每种场景模板、每个关卡→案例、结尾和最后一帧。
- [ ] 每个检查点都登记了真实存在的图片、联系表或短样片；不是只勾选“已检查”。
- [ ] 闸门未通过时没有渲染完整预览，也没有复制到成片目录。

## 技术检查

- [ ] `hyperframes lint` 无 error。
- [ ] 浏览器校验无 console error 或对比度错误。
- [ ] 布局检查无越界、重叠或溢出。
- [ ] 已抽查开头、每个章节总览、Logo 页、结尾。
- [ ] `ffprobe` 显示 H.264 视频与 AAC 音频轨道正常。
- [ ] 时长与 composition 一致，末尾没有黑帧或静音尾巴。
- [ ] 人物轨覆盖 composition 最后一帧；用户要求全程保留时，末帧人物仍可见。

## 导出

- [ ] 测试版与发布版文件名明确区分。
- [ ] 发布版从原素材重渲，不对标准质量预览做二次转码。
- [ ] 发布版使用 `--quality high --crf 10 --video-frame-format png`，除非用户指定其他格式。
- [ ] 交付时报告码率、大小和音频状态，不只报告“高清”。
- [ ] 文本密集型竖屏发布版从工程原生渲染为 `1440×2560`；不是 1080 成片机械放大，标题、字幕和小字边缘已抽查。
