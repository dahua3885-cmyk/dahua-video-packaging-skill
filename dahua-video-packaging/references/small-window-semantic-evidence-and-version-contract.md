# 语义、证据与版本冻结合同

本合同解决小窗口包装最容易反复返修的五类问题：画面早到或晚到、真实素材选错、章节与案例混在一起、在已确认版本上重新设计、字幕切句处画面跳动。

## 1. 版本冻结

- 用户说“在前面那一版基础上改”“回到之前那个基调”时，该版工程、视觉系统、信息架构、人物、字幕、封面和已确认模块是唯一底稿。
- 先建立 `freeze-ledger.md`，逐项记录：基准版本、已确认层、允许修改的时间段、允许移植的新模块、禁止变化的层。
- 局部反馈只改点名层和点名区间。不得借返修重建其他页面、换一套视觉基调或把旧版认可内容替换掉。
- 每次输出递增版本；旧版保留。最终返修必须从最近一次完整、已确认、时长正确的版本继续，不得退回更早中间母版。

## 2. 原片封面与发布封面

- 原片自带封面时，逐帧确定封面结束帧、正文第一帧和第一字音频。封面全屏只出现一次，正文人物小窗从无封面文字的第一帧开始。
- 人物、音频、字幕和语义时间线一起平移；禁止把封面帧再次缩进右下人物小窗。
- 用户确认的发布封面是独立冻结资产。正文返修不得改封面，除非用户明确点名。
- 人物开始说话时不得仍停留在仅承担选帧作用的发布封面；正文证据必须从对应句第一帧进入。

## 3. 强制语义锚点表

全片制作前建立 `semantic-evidence-map.md`，至少包含：

| 字段 | 要求 |
| --- | --- |
| `startSec / endSec` | 当前完整语义区间 |
| `spokenText` | 原音逐字文本 |
| `triggerCue / triggerFrame` | 对应对象第一次被说出的字词与帧 |
| `sectionRole` | `intro / gate / case / explanation / conclusion` |
| `visualSource` | 真实主页、作品墙、原视频、截图、人物图片或语义页 |
| `whyThisVisual` | 该画面怎样证明当前句 |
| `requiredStates` | 并列项或过程需要逐项出现的状态 |
| `persistUntil` | 同一证据应持续到哪句，避免字幕切句就换画面 |
| `frozenLayers` | 本段不可随局部返修改动的层 |
| `checkFrames` | 切换点前、中、后与边界抽帧时点 |

执行硬规则：

- 口播第一次点名账号、作品、人物、案例、关卡或步骤时，对应画面从该句第一个播放帧立即出现。
- 允许最多提前约 `0.2s` 建立上下文；不得提前展示下一项答案，也不得晚到后半句。
- 并列步骤、数字、关系和结论在口播讲到对应关键词时逐项建立；未讲到的元素保持隐藏。
- 一个完整语义可以跨多条字幕。字幕切换不是换页信号。

## 4. 真实证据选择

- 讲账号：用真实账号主页。
- 讲“发布了多少条／拆了多少条作品”：用能看见多条作品的作品墙，不复用账号主页截图冒充作品证据。
- 讲具体人物或收入案例：优先用对应原视频，并选能认出受访者、采访关系和结果的片段；只有静态结构说明时才用截图。
- 案例视频有“爆点前置”时，优先使用能快速建立人物与结果认知的开头爆点，再进入采访或解释段；若开头只有余额、数字或无上下文画面，改选更有信息量的采访片段。
- 用户点名以前已经做过的 Skill、网站、报告或案例成片时，先全盘检索并复用真实旧成片，不得用抽象卡片或重画假界面替代。
- 一张素材必须回答当前句，不回答上一句或下一句。素材可用不等于语义可用。

## 5. 章节、案例与标题层级

- “第 X 关／第 X 步／第 X 项”先使用独立介绍页，再进入对应案例证据；同类章节保持同一叙事顺序。
- 关卡标题固定为两行：第一行只放关卡序号，第二行放完整任务短语。
- 页面标题写结论或当前任务，字号服务层级，不用大而空的口号。
- 对比画面中，用户点名的比较对象是一级信息，最大、最亮；判断和解释是二级信息，不得反过来放大。
- 连续结论优先在一页内随口播递进，不为换页而拆页。
- 默认不显示“第几页／共几页”等内部页码。

## 6. 同层复用与防跳帧

- 同一个主页、作品墙、采访视频或语义页跨多句持续时，只保留一个容器并延长其时间；字幕换句时更新字幕，不新建一层近似画面。
- 禁止在边界处让两张近似截图同时做 `opacity / x / y / scale` 过渡。
- 每个视觉切换点前后至少各抽 `3` 帧；对用户点名的跳点使用逐帧联系表并连续播放 `±0.3s`。
- 画面变化只有三类合法原因：当前语义对象变化、真实过程状态变化、章节关系变化。仅字幕换行不构成画面变化理由。

## 7. 发布清晰度

- 样片允许 `1080×1920`。
- 文本密集型竖屏发布版默认从工程原生渲染 `1440×2560`；不得把 1080 成片机械放大后冒充 2K。
- 发布前抽查标题、字幕、网页小字与黄框边缘；发现发软时先提高渲染采样、字重、对比度和码率，再判断是否需要轻度锐化。
- 清晰度返修只改渲染层，不改变已确认的封面、排版、字幕时序、人物和音频。
