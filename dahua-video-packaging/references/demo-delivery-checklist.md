# 交付检查清单

## 内容与语义

- 每句口播都有对应页面、证据或明确的稳定留白理由。
- 讲作品、文案、评论、定位、信任、数据、转化和结果时，没有串错页面。
- 页面没有的数据未被虚构；定性归纳和真实计数边界清楚。
- 标准演示模式的开头总起句只交代主题，第一案例只在口播点名后出现；没有案例拼贴或结果页抢跑。
- 横屏比较模式的开头已同时展示全部真实样板并准确编号；主标题直接说清“AI 自动剪辑／包装”的主题，没有使用“一条内容，三种包装”“横屏测试”等内部占位文案。
- 每个案例的问题、过程、关键证据和结果按口播顺序闭环。
- 最后一个案例结束后不再出现任何案例录屏；结尾画面与总结语义一致。
- 字幕已专项回听否定词、容量、百分比、产品名、英文名、技术名词和结果数字。
- 讲账号使用主页、讲作品使用作品墙、讲具体案例使用对应原视频或真实旧成片，没有用近似截图串错对象。
- 每个证据从对应对象第一次被说出的播放帧进入，没有晚到后半句；允许的上下文预置不早于约 `0.2s`。
- “第 X 关／第 X 步／第 X 项”先有独立介绍页，再进入对应案例证据；同类章节顺序一致。
- 用户指定基准版本时，本版保持其视觉基调、信息架构和已确认模块，只修改点名部分。

## 构图与阅读

- 网页是主视觉，人物只是角落讲解员。
- 宽网页已优先使用横屏；核心内容在手机观看尺寸下可读。
- 横屏人物逐像素确认是 `210×352 @ (1676,690)`，圆角 `18px`，全片不移动、不缩放。
- 竖屏人物逐像素确认是 `450×445 @ (580,1285)`，字幕框是 `960×88 @ (60,1165)`，主证据落在 `x=60–1020, y=120–1080`；全片不移动、不缩放。
- 人物无白边、灰边、阴影、标签、颜色蒙层或灰层；脸部亮度和肤色未被包装层改变。
- 合成顺序是页面／黄框 → 人物 → 字幕；人物之后没有全屏调色、暗角、蓝光或灰层。
- 人物没有遮挡当前重点、字幕和核心按钮；冲突通过页面重构解决。
- 字幕逐项确认由 ffmpeg libass 渲染：`44px` 白色粗体、`BorderStyle=3`、`Outline=12`、底部居中、`MarginV=90`。
- 字幕固定、单行、无双行、无跳位、无拆词、无全宽厚底栏；文字本体宽度不超过 `1340px`，黑底外缘不超过 `x=1652`。
- 操作页看全、分析页看清、结尾页看完整。
- 比较模式逐项确认：左侧是对应类型的真实动态成片，右侧是解释文字，右下是独立讲解人物；Skill 样板保持横屏比例，小窗口样板人物头部完整。

## 运动

- 没有反复推拉、左右寻找重点或无目的漂移。
- 章节以直接切换或短交叉叠化完成。
- 黄框为 `#EBAB14 / 3px / 10px 圆角 / 0% 填充`，与目标固定保留 `10px` 空隙，线条没有穿过文字或按钮。
- 标注只在底图停稳至少 `0.12s` 后、对应关键词到达时出现，一次只标一个重点。
- 页面已经清楚、真实操作正在运动或原素材已有鼠标框选时，没有重复加框。
- 黄框没有提前出现、延续到下一句、遮挡人物／字幕或变成逐句常驻装饰。
- 每段滚动的方向、起点、终点和触发字均已验证。
- 滚动从对应句第一个字开始，并在口播需要的位置结束。
- 重要素材停留足够，不发生刚看清就切走的视觉跳。
- 同一证据跨字幕换句时复用同一容器，没有叠入第二张近似截图。
- 所有视觉切换点前后各抽 `3` 帧并连续播放，无重影、重复图层或跳动。
- 口播描述多个状态时，成片已展示相应的多个真实状态，没有一张图贯穿全过程。
- 扫描、滚动、框选、点击、执行和结果变化保持真实连续运动；加速后方向和因果顺序正确。

## 素材清洗

- 每个辅助录屏都记录了安全时间段。
- 已检查每个辅助录屏开头 `2s`、结尾 `2s` 和全片 `1fps` 抽帧。
- 成片任何抽查帧均无 OBS、录屏控制栏、错误窗口、通知、隐私路径和无关应用界面。
- 辅助录屏全部静音，主口播音频唯一。

## 关键帧

至少检查：

- 开头 Skill／工具定义。
- 第一次真实操作。
- 主要画幅或缩放切换点。
- 评论、数据或统计段。
- 最后一张完整成果页与 CTA。

滚动段另检查开始、中间、结束三帧，并连续播放确认方向与速度。

## 全片渲染闸门

- 已生成 `first_pass_gate.json`，并通过 `validate_first_pass_gate.py validate --workflow evidence-demo`。
- 代表性检查包已覆盖封面→正文、第一次真实证据、每种场景模板、每个关卡→案例、结尾和最后一帧；不是只检查开头 `3s`。
- 正文只使用固定场景语法；同类内容没有临时换模板或重新发明版式。
- 用户提供对标时，已抽取至少 `10` 张代表帧并生成项目级 `reference_contract.md`。
- 已生成对标与门槛样片的并排检查图。
- 人物、字幕、黄框的固定参数全部通过后才开始全片渲染。
- 当前画幅已使用对应 `--mode landscape|vertical` 的机器合同校验；不得用横屏合同代替竖屏合同。
- 固定项任一不通过时，版本不得标记为“完整预览”或复制到成片目录。

## 技术

- 时长与源片一致，除非用户明确授权剪辑。
- 用户只授权包装时，口播和音频确认 `0 刀`，无剪切、重排、变速、调色或替换音频。
- 分辨率、帧率、视频轨和音轨符合发布目标。
- 高质量版本从完整工程重渲，不复用低清样片。
- 原音频未被不必要二次压缩。
- 最终 MP4 可完整解码播放。
- 所有整片底图、中间母版和长时覆盖层的有效时长均覆盖完整正片。
- 最终 MP4 已每 `1–2s` 抽帧扫描，并检查 `25% / 50% / 75% / 95%` 时点；后半段无意外冻结或错误末帧循环。
- 局部返修使用的是最近一次完整已确认版本，不是更短或更早的中间资产。
- 主音频校验值符合预期；带封面版本去除封面静音段后，原正片第一字和音频完整。
- 从最终 MP4 抽帧确认改动已经进入交付文件。
- 标题或版式局部返修已生成递增版本，上一版仍存在且未被覆盖。
- 竖屏文本密集型发布版为从工程原生渲染的 `1440×2560`，不是将 1080 成片直接放大；标题、字幕、网页小字和黄框边缘已抽查。

## 发布封面（仅在要求时）

- 封面是 `1920×1080` 纯黑背景，人物来自真实源视频，无 AI 人脸、蓝光、灰层、矩形底或人物描边。
- 第一行不超过 `5` 个汉字；两行文字均为上亮下暗的独立竖向蓝色渐变。
- 用户确认人物底版后，文字返修没有重新选择或修改人物。
- 原片自带封面时只全屏出现一次；人物小窗从无封面文字的正文第一帧开始，没有重复小窗封面。
- `30fps` 视频封面固定为前 `3` 帧；第 `4` 帧进入原正片第一帧，没有做成 `1s` 片头。
- 已逐帧检查最后一帧封面和第一帧正片。

## 文件

- 工程保存在当前用户指定的独立项目目录。
- 版本递增保留，不覆盖已确认旧版。
- 预览与待确认版本留在工程目录。
- 只有用户明确确认的最终版进入用户指定的成片目录。
- 交付消息包含可点击的最终文件路径、最终时长、封面帧数和“口播是否剪切”的明确说明。
